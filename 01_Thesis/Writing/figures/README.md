# Reviewed thesis figures

For each figure, retain its editable source or generation script and a provenance note containing experiment ID, input report paths/hashes, generation command, caption, and any third-party attribution/license.

Do not move or remove original reference figures from their repositories. Copy/adapt only after checking terms; a paper's presence locally does not grant unrestricted figure reuse. Do not draw empirical curves from invented data or synthetic smoke-test results.
